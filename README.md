# Birthday gift site

1. Edit `js/content.js` — name, age, messages, image paths, music path, final sign-off (all commented).
2. Add photos to `assets/images/` named: 01-boy.jpg, 02-couple.jpg, 03-thinking-collage.jpg, 04-looking-at-each-other.jpg
3. Add your song at `assets/music/song.mp3`
4. Deploy: push this folder to a GitHub repo, then Settings → Pages → deploy from the main branch (root).
Tip: resize photos to ~1600px wide (under 500 KB each) so it loads fast on phones.
